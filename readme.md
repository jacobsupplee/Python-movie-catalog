# Media Recommendation System

## Description
This program allows the user to create and manage a movie recommendation list. The user can add
movies to the catalogue, display the current movie catalogue, or exit the program.

## Features
-Add a film to the catalogue
-Prevent duplicate entries
-Display catalogue
-Validate user input
-Program exit
