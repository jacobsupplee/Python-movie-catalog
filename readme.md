# Python Movie Catalog

A command-line app for managing a movie collection. Add titles, view the catalog, and avoid duplicate entries through a simple interactive menu.

## Features

- Add and list movie titles
- Detect duplicate entries
- Validate menu choices and user input
- Keep title formatting consistent

## Built With

- Python 3
- Lists and loops
- Input validation and exception handling

## Run

```bash
python movieRecommendations.py
```

No third-party packages are required.
